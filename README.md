# WITW+WITE 社区剧本修复版

用于 **Gary Grigsby’s War in the East 2** 的东线＋西线社区剧本。基于原社区版本 **WITW+WITE v0.9** 继续修复，当前版本为 **v0.9.64**。

这是仍有已知限制的测试版本，当前适合优先尝试双方手动控制。西线 AI 尚未修好，不应把本版本视为已完成的双方 AI 战役。

## 下载与安装

1. 取得 `WITW-WITE-v0.9.64.zip` 并解压。
2. 将压缩包中的 `Dat/Scen` 文件夹内的 `.scn` 和同名 `.txt` **一起复制**到你的 **War in the East 2 安装目录下的 `Dat/Scen` 文件夹**。
3. 在游戏的新游戏剧本列表中选择 **WITW+WITE v0.9.64**。同名 `.txt` 为选择剧本时读取的介绍；为沿用原版的文本显示方式，游戏内介绍采用英文，另附[中文剧本介绍](docs/剧本介绍.zh-CN.md)。

本项目依据 **WiTE2 v1.05.02** 开发和验证；其他版本兼容性尚未确认。需要自行安装游戏，本仓库不包含游戏程序。修改仅在剧本中，不需要替换游戏 EXE 或全局数据库。

安装后请新开战役。进行中的战役沿用存档内的港口、船池和人力数据。

## v0.9.52 跨海运输与港口

- 新开局有 349 艘共享运兵船，比 v0.9.49 多 250 艘。英国至法国和北非至西西里都从这一船池调船，准备两线同期出航时请看当回合可用数。

## 剧本背景与胜利判定

1943年夏，库尔斯克战役即将展开，西方盟军也在地中海准备继续反攻。本剧本尝试将东线、西欧与地中海的地图作战纳入同一战役：轴心国需要兼顾东线防御和西方登陆威胁，玩家2同时指挥苏军与西方盟军。

开局为1943年7月3日，最长106回合，到1945年7月6日开始结算。推荐双方手动控制。详细背景、兼容安排与玩法提示见[中文介绍](docs/剧本介绍.zh-CN.md)。

胜利等级继续使用引擎的战役规则，没有设置按城市总分划分的自定义终局档位。NO EARLY END 忽略突然胜利、突然失败与1944年底的HWM检查，但仍保留柏林陷落与到期结束。原生玩家2柏林结算分支按结束日期分级：

- 1944年12月31日及以前：玩家2决定性胜利。
- 1945年1月至3月：玩家2重大胜利。
- 1945年4月至5月：玩家2边际胜利。
- 1945年6月起、剧本到期前：平局。
- 到期仍未触发柏林陷落等结束条件：轴心国边际胜利。

盟军当前以国家12兼容，地图部队与苏军同属玩家2，不单独设置盟军胜利等级。上述日期分级已离线核对原生等级函数；实际攻占柏林后的地图／城市同步仍属未完成实测项。新增城市改变基础得分，但不会自动把上述规则改成总分胜负制。

- 尚未开展系统平衡测试及完整战役的长期稳定性测试。

## 哈士奇空降编制修复

开局第82师和英军第1空降师的六个“1/、2/、3/”分队原先没有原生分拆父单位关系，却引用完整师级TOE。原生规模函数将其算为9，超过空降候选资格的规模上限；第509独立团算为3，所以能被列出。

六个分队改用私有团／旅级TOE，第82师为团级、英军第1空降师为旅级；27条相关编制及升级链同步分摊。每个型号的三个分队目标数合计严格等于原师，该编制分摊步骤保留已有装备；本版另调整地面士气经验和开局库存，见下文。它们是原编制的抽象三等分，并非逐一复原历史伞兵团、滑翔机部队的装备表。整建制空降师仍不能直接整体投送。

七支已部署的突尼斯空降分队开局均至少50准备点，包括第82师三个团、第1空降师三个旅和第509团。50点只是最低准备度，准备度本身不包含目标，也不会自动空降。本版另为这两支部队预填哈士奇行动目标：3/82nd在149,293（杰拉以东、皮亚诺卢波方向），3/1st在154,294（锡拉库萨以南、Ponte Grande方向）。两格分别紧邻原有TF85及TF545(B)的登陆目标。英军历史上为滑翔机突击，本版仅用原生空降机制抽象。仍由玩家确认并发起。进入陆军阶段用F9的Airborne页指定目标；支援登陆须先下达两栖命令，并满足目标距离、运输机、基地、天气和堆叠等原生条件。地图比例下的目标为近似位置，依据[美国陆军官方史](https://history.army.mil/portals/143/Images/Publications/catalog/6-2.pdf)及[英国陆军战役研究](https://www.army.mod.uk/media/10745/bar-special-report-italian-campaign.pdf)。没有自动安排7月13日的Primosole作战或后续空降战役。普通空军指令不会代替空降命令。资格与规模函数离线检查通过，机场选择、装载和实际空降仍待游戏验证。

增援空军分组已改为可读的航空队／机种名称，保留日期、成员及全部操作参数。航空队卡片可能汇总未来增援，不能将其飞机数等同于单一机场的当前就绪飞机。当前用户存档第9航空队37支未来增援的倒计时均保留；Benson第22照相侦察中队就绪数为0的具体原因仍在排查，未宣称修复。

## 开局战备与盟军地面素质调整

按用户选择，仅补西线盟军开局已到场、可用地面单位／支援单位及有活跃西线机群的机场。549条记录的燃油库存补至至少原生开局需求的100%，已有超额库存保留；未来、冻结及战区外单位不获燃油赠送。苏军与轴心国记录不动。这是一次性初始库存，后续仍依赖正常后勤。

确认118处有活跃机群的西线机场原先补给、弹药、燃油全为零，本版补至原生需求；另补齐6支开局海军支援群的初始库存。需求读取自原生首次登陆前存档，加载后游戏会重新计算。皇家海军三支开局编组误用了39周延迟，按官方源身份修回0；单独的后续同名编组保留原日期。炮火是否实际参与仍受位置、损耗、弹药及原生规则约束。[官方海军规则](https://ftp.matrixgames.com/pub/WarInTheEast2/WarintheEast2Chapter25-29.pdf)。

1342条当前／后续盟军地面战斗记录的士气与兵种经验，使用增幅 `min(10, floor((100-原值)/2))`。典型值60→70、75→85、85→92、90→95。保留原有训练、老兵和精锐梯度，并逐步缩小高值增幅。这是适配当前WiTE2作战环境的剧本平衡选择，不等于历史实测统计，尚未通过系统平衡测试。HQ、舰员、机场人员、航空队和飞行员不获该素质加成；国家12的长期补充训练与国家士气规则保留。

同时修复补录中的14条错误：官方WiTW士气字段宽度为16位，之前误读相邻移动值导致截到100。先恢复60／70／75等正确基值，再应用上述规则。装备数量、损坏、疲劳、将领、生产、人力与胜利条件保留。

七支突尼斯已部署空降分队均至少50准备点，其余历史目标和兵力保留；未预设目标的分队仍须玩家选择目标。F9→Airborne，使用右键选择合适的出发机场；支援登陆须先下达两栖命令。首回合可下令与随后入侵阶段实际执行应区别看待。[操作手册](https://ftp.matrixgames.com/pub/WarInTheEast2/WarintheEast2Chapter35-37.pdf)。准备点、油料补足不代表已经验证装载或投送成功。

基准核对发现：此前美军第1师60／60与官方WiTW一致，而西西里第15装甲掷弹兵师沿用WiTE2的86／86，WiTW同期为75／75；HG本部的比较还涉及Schmalz战斗群及拆分编组差异。德军数据本版保留，不能将此比较当作同兵力实战结论。见[data/combat-reference.json](data/combat-reference.json)。
