# WITW+WITE v0.9.43 剧本介绍

1943年夏，库尔斯克战役即将展开，西方盟军在地中海准备继续反攻。德国及其盟国必须同时应对东线压力与西方登陆威胁。你将选择轴心国，或同时指挥苏军与西方盟军，在欧洲展开一场跨战线战役。

本剧本基于社区WITW+WITE v0.9继续修复，尝试在WiTE2地图上结合东线、西欧和地中海的作战。开局日期1943年7月3日，最长106回合，至1945年7月6日开始结算；柏林陷落仍可能使战役提前结束。

盟军海外后勤与装备分配采用分期配额，并保留有限人力补充与共享池限制。开局库存缺口已修正；新增四条开局空军默认任务，六个哈士奇空降分队改用团／旅级编制。具体数值、历史依据与待验证范围见README；这些取值不等于完整历史统计。

修复内容包括部分盟军玩家归属、HQ指挥链、增援、装备补充、空军与登陆数据，并增加欧洲城市与工业目标。目前共有163个计分城市，涵盖鲁尔、西里西亚、西欧、意大利、巴尔干及东线工业与交通中心。

推荐双方手动控制。西线战略AI仍有将部队调往东线的问题，暂不能保证任意一方电脑控制时的完整西线体验。盟军以国家12维持玩家控制，仍共享苏军阵营的部分国家池与将领规则；后续替换将领可能出现苏军人物。

部分未来单位已经提前预置并冻结，部分主官也提前预填；这些是兼容安排，不代表1943年历史上已在该地任职。单位启用时间与历史任职时间的差异见将领记录。没有编写完整的后续历史将领交接。

胜利等级沿用游戏战役规则。NO EARLY END关闭突然胜利、突然失败和1944年底HWM检查，保留柏林陷落与剧本到期结算。原生玩家2柏林分支在1944年底前为决定性胜利，1945年1—3月为重大胜利，4—5月为边际胜利，6月起至到期前为平局；到期仍未满足结束条件为轴心国边际胜利。城市基础分不是自定义终局胜负档位。

本版本依据WiTE2 v1.05.02制作。已通过若干短期功能测试与静态检查，尚未完成系统平衡、完整战役长期稳定性及所有1944—45年自然升级流程的验证。具体已知限制以README为准。

本版恢复官方战役中有日期的1010条地面和198条航空增援，并适度下调德军总动员事件的长期人力加成。增援采用日期抵达与预置冻结结合；新增大批次仍需合并运行检查。见[详细范围](盟军增援核对.zh-CN.md)。

本版补齐西线盟军开局陆军／支援／机场燃油，修复118处机场零库存与皇家海军开局编组延迟；盟军地面士气、经验按保留梯度的规则提高。七支突尼斯空降分队开局至少50准备点。仅初始数据与短期功能修复，实际空军／空降／舰炮及平衡仍待合并验证。
