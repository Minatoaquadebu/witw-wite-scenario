# 盟军增援核对

本文件对应v0.9.38。参考为本地官方《WITW》1943—45战役；日期从1943年7月3日按周换算，迟于战役到期的记录不计作期内正常增援。官方游戏名单也不是独立历史档案考证。

匹配使用番号、原国籍、兵种类型与编制后缀；仅对引号、口径后缀、静态防空标签等已列明的差异做唯一匹配。两处运输航空军HQ按已知转换关系人工对应。名称歧义、分拆记录和过期记录保留待审，没有自动强行配对。


## 盟军增援完整性与本版修复

本版对本地官方《WITW》1943—45战役全部1772条有名称的玩家2地面／HQ／机场记录做了静态对照，其中742条开局记录、1010条战役期内后续记录、20条特殊或超期记录。**这不是历史全部部队已完整恢复的声明，也不是空军飞行中队全名单审计。**

本版修复12支部队：美军第6、8、14、16、20装甲师，英军第1装甲师、南非第6装甲师，TF O/U两支美军登陆HQ，以及铁路群A/B/C。修复归属、启用日期与必要的预置／编制兼容；铁路群沿用官方剧本的1944年1月22日、4月29日、8月19日日期，不能把通用A/B/C标签解释成已经考证出的具体历史番号。

预置冻结数量由99增至110；冻结单位已在地图上，常规增援表无法完整列出它们。英军第1装甲师保留突尼斯正常增援方式。第6美军装甲师在原官方记录中没有指定地图落点，本版采用已预置上级HQ附近的英国兼容地点，不声称恢复了精确历史入港地。

对照后的待复核项仍包括1154条匹配记录，其当前启用时间在战役期限之外，其中814条对应官方后续增援；另有65条未匹配、6条身份有歧义、39条非活动／分拆备用记录。不能将这些数字直接当作应新增的历史部队数量，也没有把它们全部启用。逐项名单见[data/reinforcements.json](../data/reinforcements.json)，说明见[增援核对记录](盟军增援核对.zh-CN.md)。

## 有限的盟军人力补充

开局安排10万人一次性额外配额；1943年8—12月每月1.5万人，1944年1—9月每月3万人，1944年10月—1945年6月每月2万人，总计62.5万人。配额通过24个一次性事件进入国家12共享人力池，日历日期在适用的周回合事件检查时执行。旧存档不自动取得这些事件。

这组数值是参考历史补充兵约束制定的有限剧本配额，不是史料逐月人数的复原；不将已编入部队的人和伤愈归队者再作为新增人力重复计算。美国陆军官方史记载1944年秋冬补充兵短缺，因此没有提供无限补充，也没有把全国动员总人数加入战区池。[参考资料](https://history.army.mil/Portals/143/Images/Publications/Publication%20By%20Title%20Images/L%20Pdf/CMH_Pub_7-3-1.pdf)

人力仍与苏军共享，无法锁定只给盟军部队使用。新事件和新启用批次目前通过静态结构与保留检查，**尚未完成游戏内实际入池／到达测试**。不需要为本轮静态核对手动推进到1944年。
