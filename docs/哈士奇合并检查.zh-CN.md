# 哈士奇开局合并检查

使用v0.9.44普通版或绿色符号版新开局，双方Human。无需推进至1944年，也不要覆盖正在玩的旧档。

1. 开局空军阶段，在Tactical Air Force中确认新增两条Ground Attack：中心149,292、半径5；分别以Unit与Interdict为高优先级。保留预设，执行空军阶段。查看本轮空军日志是否出现对地攻击／遮断，而非只有侦察。
2. 陆军阶段确认第2军、第7集团军在瓦莱塔，第15集团军群在比塞大。沿用预定哈士奇登陆，特别确认TF81与第1师目标已是149,293，第45师为149,294。保留两栖HQ邻接海滩，勿把TF81重新改回杰拉港。
3. 保存一份登陆前档，推进至入侵落地及轴心国可行动阶段。检查149,293是否生成临时港、第1与第45师是否处于相邻滩头；另存一份反击前档。如重现集中反击，再保存战斗后的档及报告。
4. 把上述保存结果和本轮空军日志一起留存，即可统一核对命令执行、临时港及战斗变化。不要仅凭一次守住／投降就判定平衡已通过。

军部还在马耳他，距海滩10格，未满足支援单位参战所需的5格。下个可行动的盟军陆军阶段，可通过普通海运把地面HQ运到已控制海滩附近；这与两栖HQ自动落地是两回事。

准备点、历史空降目标及已修复空降团／旅保持不变；如果本次顺便下达空降命令，也可把投送结果一并保留，无需另起一轮测试。不要为这轮测试手动推到1944年。
