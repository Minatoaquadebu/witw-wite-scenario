# 哈士奇合并检查

新开v0.9.46可获得完整新配置；既有局的独立修复副本可保留已执行的空军和已发起的其他登陆。

1. 陆军阶段选TF81，目标应显示147,293，出海位置147,294；点击INVADE并确认能否出海。不要继续用149,293作为登陆目标，它是内陆空降格。
2. 确认TF85已向149,294发起入侵，再F9→Airborne，选择突尼斯的3/82nd、可用出发机场和目标149,293，下达首波空降命令。其他分队可参考README可选目标，留意运输机剩余容量。
3. 在所有登陆／空降命令下达后另存，再结束陆军阶段。保留发船前、落地后的档和日志，可在一次推进中检查临时港、空降散落、堆叠及反击。

本版六支两栖HQ和七支空降分队的目标邻接，已经按实际native shape2重新检查；不再使用此前错误的shape3模型。单位资格／数据检查不代替实际装载、发船和落地验证。
