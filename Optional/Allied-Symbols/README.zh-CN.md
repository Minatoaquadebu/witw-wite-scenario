# 可选盟军绿色符号

此包使用单独的“WITW+WITE v0.9.48 Allied Symbols”剧本。它与普通版的全部游戏数据相同，仅修改剧本名称和部分西线编制的图标索引。绿色兵种符号用于区分盟军与苏军，国家底色保持原样。

## 安装

1. 先安装主剧本。
2. 备份游戏`Dat/Art/Units`中本包同名的12个贴图文件。
3. 将本目录的`Dat`文件夹合并复制到WiTE2安装目录；既要复制`Art/Units`，也要复制`Scen`中的可选剧本及同名介绍。
4. 新开局选择`WITW+WITE v0.9.48 Allied Symbols`。

没有复制贴图时，请使用普通剧本；可选剧本引用了原版空白图标槽位，缺少贴图会使相应符号不可见。不要只复制可选SCN。

支持步兵、装甲、空降、炮兵、反坦克、防空、普通HQ、工兵和铁路九类符号。普通指挥HQ使用HQ标记；工程和施工单位使用工兵标记，铁路修复／施工单位使用铁路标记。特殊预设符号、其他兵种、机场和登陆HQ保持原样。最小9x9缩放本就不显示这些兵种图形，不承诺该缩放下可区分。绿色是统一西线标识，不代表建立了独立国籍或人力池。

12张贴图只向9个透明空槽添加符号，原有像素逐一核对保持不变，NATO和非NATO两套均已处理。原版剧本没有使用这些新增索引；其他使用相同空槽的美术模组可能冲突。卸载时恢复备份贴图，并改用普通版剧本。

目前已检查贴图尺寸、像素保留和剧本数据一致性，尚未在游戏内目视验证。依据本地更新记录，合法自定义索引范围为100—127、208—227；本包使用123—127、208与225—227。

此前版本的高级HQ、反坦克、防空图案映射已修正。替换贴图并重启游戏后，旧可选版存档原先引用的127、225、226槽会显示修正后的HQ、反坦克、防空图案。新增的军／集团军HQ、工程兵着色需要新的剧本索引，旧存档不会自动获得全部扩展；旧版普通施工单位原用铁路槽的问题也需单独修正存档索引。
