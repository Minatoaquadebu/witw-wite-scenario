# 可选盟军绿色符号

此包使用单独的“WITW+WITE v0.9.63 Allied Symbols”剧本。它与普通版的全部游戏数据相同，仅修改剧本名称和部分西线编制的图标索引。绿色兵种符号用于区分盟军与苏军，国家底色保持原样。

## 安装

1. 先安装主剧本。
2. 备份游戏`Dat/Art/Units`中本包同名的12个贴图文件。
3. 将本目录的`Dat`文件夹合并复制到WiTE2安装目录；既要复制`Art/Units`，也要复制`Scen`中的可选剧本及同名介绍。
4. 新开局选择`WITW+WITE v0.9.63 Allied Symbols`。

没有复制贴图时，请使用普通剧本；可选剧本引用了原版空白图标槽位，缺少贴图会使相应符号不可见。不要只复制可选SCN。

支持步兵、装甲、空降、炮兵、反坦克、防空、普通HQ、工兵和铁路九类符号。普通指挥HQ使用HQ标记；工程和施工单位使用工兵标记，铁路修复／施工单位使用铁路标记。特殊预设符号、其他兵种、机场和登陆HQ保持原样。最小9x9缩放本就不显示这些兵种图形，不承诺该缩放下可区分。绿色是统一西线标识，不代表建立了独立国籍或人力池。

12张贴图只向9个透明空槽添加符号，原有像素逐一核对保持不变，NATO和非NATO两套均已处理。原版剧本没有使用这些新增索引；其他使用相同空槽的美术模组可能冲突。卸载时恢复备份贴图，并改用普通版剧本。

目前已检查贴图尺寸、像素保留和剧本数据一致性，尚未在游戏内目视验证。依据本地更新记录，合法自定义索引范围为100—127、208—227；本包使用123—127、208与225—227。

此前版本的高级HQ、反坦克、防空图案映射已修正。替换贴图并重启游戏后，旧可选版存档原先引用的127、225、226槽会显示修正后的HQ、反坦克、防空图案。新增的军／集团军HQ、工程兵着色需要新的剧本索引，旧存档不会自动获得全部扩展；旧版普通施工单位原用铁路槽的问题也需单独修正存档索引。

## v0.9.63 盟军地面部队集结地点

126 支西方盟军后续地面部队恢复开局预置和原定冻结期限，英国 76 支，北非 50 支。124 支在原集结格，美军第 97 步兵师和第 106 骑兵群因堆叠上限各移至英国相邻一格。沿用 v0.9.62 的开局装备，冻结期间游戏后勤仍可能换装。修改对新开战役生效。

## v0.9.62 盟军装备、部队与轴心部署

巴黎和威尼斯各设一支德军铁路司令部。235 支原战区轴心航空单位按期部署到地图机场。补入英国本土 9 个师，126 支后续地面部队按期携装入场。校正 373 支开局航空单位和 198 支航空增援。按官方西线战役恢复开局可领的 77 种地面装备和 5,793 架备用机，调整谢尔曼与 P-51 的供货，并区分美军陆军和英联邦中型坦克的替换型号。 西方航空单位专用机型通过苏盟玩家的库存补充。历史编制、厂产、部队实收与测试设置详见包内《v0.9.62-历史核对与实测》。 重新校准德国、法国和保护国卡车工厂的产能，并将德国主要产能集中于勃兰登堡、科隆和加格瑙。

## v0.9.61 盟军装备和西线补给站

美军 M4A3(76)W 的雷克瑟姆工厂容量从 2 调到 74。唐卡斯特原有的两条谢尔曼线按游戏规则改产 75W 和 M4A1(76)W。补入 F-6C、F-5B、剑鱼 II、文图拉 GR.V 四条成品机产线。德国、法国和低地、意大利、巴尔干、英国及北非与埃及合计新增 41 座仓库。新开战役生效。
